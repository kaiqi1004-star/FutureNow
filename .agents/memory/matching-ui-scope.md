description: Preserve FutureNow matching behavior while refining its presentation.

For FutureNow matching-screen UI refinements, keep scoring weights, ranking, source records, skill-equivalence rules, profile privacy boundaries, and SDG logic unchanged unless the user asks for a behavioral change.

**Why:** The user repeatedly scoped these refinements to presentation and usability, with match values and evidence remaining unchanged.

**How to apply:** Treat card and detail-page changes as display-only. If a requested presentation change would require altering calculations, source data, or transmitted profile fields, clarify that boundary first.
